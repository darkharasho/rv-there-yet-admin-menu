# v0.1 test build: brief

First in-game test build of RVAdminMenu. Goal: a menu the host can open in a live
session to try every action once. The user cares most about **teleport to the RV** and
**teleport to checkpoint**. Facts below come from the 2026-10-30 dump
(`docs/game-objects.md`, raw headers in `~/.cache/rv-recon/dump/CXXHeaderDump/`).

## Fixed decisions
- **Package layout.** The zip root holds `manifest.json`, `icon.png`, `README.md`,
  `config.ini`, `enabled.txt`, `scripts/`, which are the *contents* of `mod/`, not a
  `mod/` subfolder. HML extracts the zip into `shimloader/mod/<Name>/`, and UE4SS loads
  `<Name>/scripts/main.lua`. Fix `scripts/build-package.sh` and `tests/package_spec.lua`.
- **Module loading.** `main.lua` works out its own directory with
  `debug.getinfo(1,"S").source` (MoreRVers does the same) and prepends
  `<dir>/?.lua` to `package.path`, then `require("lib.config")` etc. Read
  `config.ini` from `<dir>/../config.ini`.
- **Key names.** Fix `config.lua` KEY_NAMES: `INS` and `DEL`, not INSERT/DELETE. All of
  F1–F12, INS, HOME, END, DEL, PAGE_UP, PAGE_DOWN are now confirmed. Remove the
  UNVERIFIED comments here and in `config.ini`. Default hotkey stays F3.
- **Input.** Keyboard only in v0.1. The hotkey toggles the menu. UP_ARROW and
  DOWN_ARROW move the selection, RETURN or RIGHT_ARROW selects, BACKSPACE or LEFT_ARROW
  goes back (and closes the menu at the root). Bind each with `RegisterKeyBind(Key.X, fn)`.
  The handlers do nothing while the menu is closed. Every handler runs its body
  through `ExecuteInGameThread`. Mouse support is out of scope for v0.1.
- **Rendering: UMG built from Lua** (the HUD draw hook never fires). New module
  `lib/overlay.lua`:
  ```lua
  local W = StaticFindObject("/Script/UMG.UserWidget")
  local widget = StaticConstructObject(W, gameInstanceOrPC, FName("RVAdminMenuWidget"))
  widget.WidgetTree = StaticConstructObject(StaticFindObject("/Script/UMG.WidgetTree"), widget, FName("RVAdminTree"))
  local canvas = StaticConstructObject(StaticFindObject("/Script/UMG.CanvasPanel"), widget.WidgetTree, FName("RVAdminCanvas"))
  widget.WidgetTree.RootWidget = canvas
  local border = StaticConstructObject(StaticFindObject("/Script/UMG.Border"), widget.WidgetTree, FName("RVAdminBorder"))
  border:SetBrushColor({R=0,G=0,B=0,A=0.7}); border:SetPadding({Left=12,Top=8,Right=12,Bottom=8})
  local slot = canvas:AddChildToCanvas(border)  -- slot:SetPosition({X=40,Y=120}); slot:SetAutoSize(true)
  local text = StaticConstructObject(StaticFindObject("/Script/UMG.TextBlock"), widget.WidgetTree, FName("RVAdminText"))
  border:SetContent(text)
  widget:AddToViewport(1000)
  text:SetText(FText(str))   -- redraw = one SetText of the whole menu as lines
  widget:SetVisibility(1|0)  -- ESlateVisibility: 0 Visible, 1 Collapsed, 2 Hidden, 3 HitTestInvisible
  ```
  - Draw the whole menu as one multi-line string. Title first, then rows with `> ` for
    the selected row, `[ON]`/`[OFF]` for toggles and `...` for submenus, then the
    confirm prompt and message lines. Build that string in a **pure** function
    (`overlay.format(view)`) and unit-test it.
  - Create the widget lazily the first time the menu opens. If the widget becomes
    invalid (level change), recreate it.
  - Every step is pcall-guarded. If UMG fails, log one warning, plus each menu redraw
    as INFO lines, so the user can at least read the log. Never crash.
- **Authority.** `is_host()` is true when `FindFirstOf("GameModeBase")` is valid.
  - **Self actions** work on a client too: they go through the local cheat manager or
    the local pawn.
  - **Actions on other players** are host-only. On a client, show the message
    "Host only".

## Menu tree (v0.1)
```
RV Admin
  Teleport ...
    Me to RV                         (cheat TeleportToVehicle)
    Everyone to RV                   (host)
    Me to checkpoint ...             (0..15, cheat TeleportToCheckpoint(n))
    Everyone to checkpoint ...       (host; loaded BP_CheckPoint_C actors, by CheckpointIndex)
    Restart at checkpoint ...        (destructive; cheat RestartAtCheckpoint(n), 0..15)
    Bring everyone to me             (host)
    Bring RV to me                   (host; vehicle ForceTeleport)
  Players ...                        (host; rebuilt each time it opens, one entry per player name)
    <name> ...
      Teleport to me / Teleport me to them / Send to RV
      Revive / Heal / Kill (destructive)
      Free from grab / Force unseat
      God mode (toggle) / Speed x2 (toggle)
  Everyone ...                       (host)
    Revive all / Heal all / Free all from grabs / God mode all (toggle)
  Me ...
    God mode (toggle; GodPlayers via cheat on host, else own Server_UpdateInvulnerable)
    Revive me (cheat RevivePlayer) / Heal me / Give 5 epipens (cheat GiveEpiPens(5))
  Spawn item ...                     (cheat SpawnItemInFrontOfPlayer(class); list below)
```
`menu.lua` takes a static spec. Add dynamic pages to it: an item can have
`kind="submenu"` with `build = function() return page end`, called when it opens. Keep
`menu.lua` engine-free and add tests for the dynamic pages.

## Engine recipes
Wrap every call in the `ue.lua` adapter (`adapter:call`, pcall-guarded). Pass structs as
Lua tables: FVector `{X=,Y=,Z=}`, FRotator `{Pitch=,Yaw=,Roll=}`, FQuat `{X=0,Y=0,Z=0,W=1}`.
Write unwrapping helpers for FString (`:ToString()`) and objects (`:IsValid()`).

- **Local controller:** among `FindAllOf("BP_FirstPersonPlayerController_C")`, the one
  where `IsLocalController()` is true. Fall back to `FindFirstOf("PlayerController")`.
- **Local pawn:** `pc.Pawn`. **Cheat manager:** `pc.CheatManager` (`BP_CheatManager_C`,
  created by the bundled CheatManagerEnablerMod).
- **Players:** `FindAllOf("BP_FirstPersonCharacter_C")`, keeping valid ones. Name is
  `pawn.PlayerState:GetPlayerName():ToString()`, falling back to `"Player N"`. Re-find
  the target by name or address at action time, and say "player no longer in session"
  if it's gone.
- **Location:** `actor:K2_GetActorLocation()`. Rotation: `actor:K2_GetActorRotation()`.
- **Teleport player P to location L** (`lib/actions.lua: teleport(P, L)`):
  1. `P:TeleportPlayerTo(L, rot)` (C++ `ARGFirstPersonCharacter`).
  2. If P is not the local pawn, also `P:Client_MovePlayerAfterRevive(L)`, because
     movement is client-authoritative and this Client RPC runs on their machine.
  3. Add an offset so players don't stack: put each player 120 units apart in a
     ring around L, and raise Z by 50.
- **RV:** `FindFirstOf("BP_VehicleBase_C")` (the Winnebago is `BP_Vehicle_Winnebago_01_C`).
  - **Send a player to the RV:** teleport to the RV's location, plus Z+250 to land on
    the roof/beside it rather than inside the mesh, plus a ring offset. Mark the offset
    as a guess in a comment.
  - **Me to RV:** prefer the cheat `TeleportToVehicle()` and fall back to the recipe above.
  - **Bring the RV to me:** `vehicle:ForceTeleport(myLoc + forward*600 + Z 100)`.
- **Checkpoints:** `FindAllOf("BP_CheckPoint_C")`, each with `.CheckpointIndex`
  (int32) and its actor location. They stream in, so the "Everyone to checkpoint" page
  lists only the loaded ones, sorted by index, and says "no checkpoints loaded" if
  there are none. "Me to checkpoint n" uses the cheat `TeleportToCheckpoint(n)`.
- **Revive P:** `localPawn:ServerReviveTarget(P, true, true, localPawn)`. Fallback:
  `localPawn:Server_RevivePlayerAtLocation(P, P location)`.
- **Heal P:** read `P.CurrentDamage` (TArray<FTagIntPair{FGameplayTag Tag; int32 Value}>),
  build `FST_Damage_Results` with one entry per pair, and call
  `localPawn:Server_HealPlayerDamage(P, results)`. Struct field names (exact):
  ```
  FST_Damage_Results { DamageResults_3_42A87BC046D21D82BBBC0E856286E2CD = { ...FST_Damage_Result } }
  FST_Damage_Result {
    DamageType_3_42A87BC046D21D82BBBC0E856286E2CD = { TagName = FName(tag) },
    Damage_7_F3292EDF44790F4AED9654BACA71838A = value,
    MaxVehicleShieldConsumption_10_E95C0831458EF361CE55AF89624199AE = 0,
    SkipVehicleShield_12_17FC8070442367387C3CBFB05060541B = true }
  ```
  - Copy the tag across: use `pair.Tag.TagName` as-is when passing, or
    `:ToString()` → `FName`.
  - If CurrentDamage is empty, say "already at full health".
- **Kill P:** `localPawn:Server_TakePlayerDamage(P, results{tag "Damage.Default",
  damage = P.DeathDamageThreshold + 1}, true)`. `Damage.Default` exists in the ObjectDump.
- **God P:** `P:Server_UpdateInvulnerable(bool)`. Read the current state from
  `P.Invulnerable`. **Speed:** `localPawn:Server_UpdateSpeedMultiplier(P, 2.0 or 1.0, 0)`.
  Time 0 is a guess for "no expiry"; note it.
- **Free P from grab:**
  1. For every other character H where `H.CurrentPickUpActor` or
     `H.Current3rdPersonPickUpActor` equals P (compare `GetAddress()`), call
     `H:Server_DropActor(P, 0.0, false, {0,0,0}, false, {0,0,0,1}, {0,0,0})`, then
     `H:TryToClearPickedUpActor(P)`.
  2. Then do the force unseat (next item) as well, because monster and monkey grabs are
     seats.
  3. Then `P:Server_Ragdoll(false)`.
- **Force unseat P:** `parent = P:GetAttachParentActor()`. If it's valid:
  `P:Client_ForceUnseat(parent)`, `P:Server_SitOnRideableActor(parent, false, 0)`, and
  if P is still attached, `P:K2_DetachFromActor(1,1,1)` (KeepWorld). If P isn't seated,
  say "not seated". The force unseat is also its own menu item.
- **Spawn items:** the class list comes from `cheatManager.RegisteredItemCommands`, a
  `TMap<FString, TSubclassOf<ARGInteractableActor>>`.
  - Iterate it with `map:ForEach(function(k, v) ... k:get():ToString(), v:get() end)`.
  - Sort by name and page it 15 per page, with "Next page ..." entries.
  - Spawn with `cheat:SpawnItemInFrontOfPlayer(class)`, falling back to
    `cheat:GiveItem(class)`.
  - If the map is empty or unreadable, show "no item list available".

## Engineering rules
- Every UE4SS global is looked up with rawget and type-checked. Every engine call is
  pcall-guarded. A failed action sets the menu message to the short error text and
  logs it. It never throws.
- Put action logic in `lib/actions.lua` and take the adapter as an injected dependency,
  so the busted tests can drive it with `tests/support/fake_ue.lua`. Extend the fake
  as needed.
- Tests: `nice -n 19 taskset -c 0-3 scripts/test.sh`. Keep the existing tests green and
  add tests for `overlay.format`, the dynamic pages, the teleport ring offsets, the heal
  struct building and the host gating.
- Update `README.md` with keys and features, and replace the Unity/BepInEx description
  in the repo `CLAUDE.md` with UE5.6 + UE4SS Lua via unreal_shimloader, installed
  through HML.
- Version 0.1.0. Bump `CHANGELOG.md`. Build with `scripts/build-package.sh`, then check
  that `unzip -l` shows `scripts/main.lua` at the root.
- **Do not commit.**
